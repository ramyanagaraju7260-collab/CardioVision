# PREMIUM VISUAL ASSET REQUIREMENTS

## CRITICAL DESIGN RULE
- DO NOT use placeholder images.
- DO NOT use random Unsplash office photos.
- DO NOT use generic doctor-and-patient stock photos.
- DO NOT use smiling doctors shaking hands.
- DO NOT use cartoon medical illustrations.
- DO NOT use clipart.
- DO NOT use low-resolution PNGs.
- DO NOT use outdated medical graphics.
- Every image in this project must feel premium, modern, scientific, and suitable for a flagship AI healthcare platform.

## IMAGE SOURCING POLICY
Whenever visual assets are required, use only high-quality royalty-free images or illustrations from trusted sources.
Preferred sources (in order of priority):
- Unsplash
- Pexels
- Freepik (free assets with attribution where required)
- Storyset
- Icons8 Illustrations
- Adobe Stock (if licensed assets are available)
- Sketchfab (for free 3D models)
- Spline Community
- CGTrader (Free)
- TurboSquid (Free)
Never use low-quality screenshots, watermarked assets, or random internet images.

## HERO SECTION VISUALS
The landing page hero must include premium medical visuals.
Preferred imagery:
- High-quality 3D human heart render
- Retina fundus close-up
- AI healthcare hologram
- Neural network visualization
- Floating biotechnology particles
- Medical data visualization
- Scientific laboratory environment
- Transparent anatomy render
- Futuristic healthcare illustration

Search keywords: "AI Healthcare", "Medical Technology", "3D Heart Anatomy", "Retinal Fundus", "Medical Innovation", "Digital Health", "Biotechnology", "Future Medicine"

## RETINAL IMAGES
This project focuses on retinal fundus analysis.
Always use REAL retinal fundus images.
Never substitute retina photographs with generic eye photos.
Preferred datasets and image sources: EyePACS, APTOS Blindness Detection, DRIVE Dataset, STARE Dataset, HRF Dataset, Messidor Dataset.
These images should be used wherever retinal examples are required.

## 3D MEDICAL ASSETS
Whenever a 3D scene or illustration is needed, use premium anatomical models.
Preferred objects: Human Heart, Retina, Human Eye, Blood Vessel Network, DNA Helix, AI Brain, Cardiovascular System, Neural Connections, Medical Chip, Medical Hologram.
Preferred asset sources: Sketchfab, Spline Community, CGTrader, TurboSquid.

## FEATURE SECTION IMAGES
Every major section should include a relevant premium illustration.
Examples:
- Heart Risk Prediction → 3D Heart
- Retinal Analysis → Retina Fundus Image
- Explainable AI → AI Heatmap Overlay
- Clinical Intelligence → Medical Dashboard Illustration
- Prediction Engine → Neural Network Visualization
- Healthcare Analytics → Interactive Medical Charts

## BACKGROUND VISUALS
Use elegant medical-themed backgrounds.
Examples: Soft medical gradients, Scientific mesh gradients, Floating particles, DNA patterns, Neural connections, Retinal vessel textures, Microscopic biological structures, Digital healthcare grids.
Do NOT use noisy backgrounds. Keep the interface clean and premium.

## ICONOGRAPHY
Use modern medical icons.
Preferred libraries: Lucide, Phosphor, Heroicons, Tabler Icons.
Icons should be: Minimal, Outlined, Consistent, Modern, Medical.

## IMAGE QUALITY
Every image should be: Ultra HD, Professional, Consistent color grading, Bright, Premium, Modern, Scientific, Future-oriented.
Use WebP format where possible for performance.

## VISUAL STORYTELLING
Each page should tell a visual story.
- Landing Page → Futuristic AI Healthcare
- Retinal Upload → AI Vision
- Prediction → Medical Intelligence
- Model Insights → Scientific Explainability
- Analytics → Healthcare Intelligence
- Reports → Clinical Decision Support
Avoid empty white areas without purpose.

## ANIMATION OF VISUALS
Medical illustrations should include subtle animations when appropriate:
Floating motion, Parallax, Soft glow, Gradient movement, Particle animation, Neural pulse animation, Retina scanning line, Heart pulse effect, DNA rotation, Micro-interactions.
Animations must remain elegant and not distract from usability.

## FINAL VISUAL GOAL
The final application should look like a flagship AI healthcare platform showcased by Apple, NVIDIA Healthcare, Siemens Healthineers, or Philips Healthcare.
Every visual asset must reinforce trust, innovation, and scientific credibility.
If a suitable premium medical image is not available, prefer a clean abstract medical illustration over a generic stock photo.
Visual quality is a first-class requirement and should never be sacrificed for convenience.

## LAYOUT & ARCHITECTURE
- DO NOT use a traditional fixed left sidebar layout. The application must initially feel like a premium SaaS website, not an admin panel.
- Use floating navigation, top navigation, or an expandable floating dock.
- Use full-width layouts where applicable.
- The dashboard should appear only after entering the application from a dedicated landing page.
- Use asymmetric sections, immersive cards, and bento grid layouts instead of basic linear lists.
